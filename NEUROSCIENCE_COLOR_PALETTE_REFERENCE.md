## 📊 COLOR USAGE GUIDELINES

### Saturation Levels

```
Primary Elements (Buttons, Headers):
- Saturation: 40-50%
- Example: #5B8DBE (40% saturation)
- Effect: Professional, trustworthy

Secondary Elements (Accents, Highlights):
- Saturation: 30-40%
- Example: #7BA3C0 (35% saturation)
- Effect: Subtle, supporting

Backgrounds:
- Saturation: 10-20%
- Example: #F5F3F8 (33% saturation)
- Effect: Soft, non-intrusive

Accents:
- Saturation: 50-60%
- Example: #E8956F (75% saturation)
- Effect: Energetic, attention-grabbing
```

### Opacity Levels

```
Full Opacity (100%):
- Primary text
- Primary buttons
- Key elements
- Important information

High Opacity (80-90%):
- Secondary text
- Secondary buttons
- Supporting elements
- Secondary information

Medium Opacity (50-70%):
- Disabled states
- Placeholder text
- Subtle backgrounds
- Hover states

Low Opacity (20-40%):
- Borders
- Dividers
- Subtle backgrounds
- Overlay effects
```

### Contrast Ratios

```
Text on Background:
- Normal text: 4.5:1 (WCAG AA)
- Large text: 3:1 (WCAG AA)
- Minimum: 3:1 (WCAG A)

UI Components:
- Buttons: 3:1 (WCAG AA)
- Links: 3:1 (WCAG AA)
- Icons: 3:1 (WCAG AA)

Recommended:
- Aim for 7:1+ (WCAG AAA)
- Test with WebAIM tool
- Check on different devices
```

## 🧠 NEUROSCIENCE PRINCIPLES APPLIED

### 1. Color Psychology
- **Blue (#5B8DBE):** Increases trust and focus
- **Coral (#E8956F):** Increases engagement and warmth
- **Green (#7CB342):** Promotes calmness and well-being

### 2. Eye Strain Reduction
- Desaturated colors (40-50% saturation)
- Warm-tinted neutrals instead of cool grays
- Soft backgrounds (#FDFBF8) instead of pure white

### 3. Emotional Design
- Warm colors for approachability
- Cool colors for trust
- Balanced palette for harmony

### 4. Accessibility
- WCAG 2.1 AA compliant contrast ratios
- Semantic colors for clarity
- Multiple ways to convey information

### 5. Visual Hierarchy
- Primary color for key elements
- Secondary color for CTAs
- Accent color for success/growth
- Neutral colors for supporting content
